# Changelog

All notable user-visible changes are listed here. Versions marked *prerelease* are experimental.

## [Unreleased]

- Public documentation, security and contributor guidance are being expanded.

## [0.7.0] — prerelease

- Android language selector: German and English.
- Android appearance selector: system, light and dark.
- Bridge sends language and appearance preference to the watch; watch labels and palette follow.
- Updated screenshot guidance, installation docs and public GitHub README.

## [0.6.0] — prerelease

- Up to six custom watch pages with four slots each.
- Interactive watch preview and page editor on Android, including names, aliases and reordering.
- Swipe, crown and arrow page navigation.
- Simplified watch search by category; Assistant removed.
- Reduced unnecessary watch re-renders.

## [0.5.1] — prerelease

- Improved entity selection by allowing taps on the card and checkbox.
- Android system-bar inset fix and adjusted round-watch typography/layout.

## [0.5.0] — prerelease

- Four Android navigation areas and high-contrast UI.
- Fullscreen entity search with filters and watch favourites.
- Watch entity search and phone-mediated Home Assistant Assist prototype (removed in v0.6).

## [0.4.0] — prerelease

- Room browsing and lock/unlock confirmation flow.
- Android launcher icon and entity filters.

## [0.3.0] — prerelease

- Initial redesigned Android/watch bridge experience and build artefacts.
